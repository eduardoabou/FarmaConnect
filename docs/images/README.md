# Imagens do portfólio

Adicione aqui capturas sem credenciais, e-mails reais, chaves, identificadores privados ou informações de clientes.

Arquivos sugeridos:

- `login.png` — tela de autenticação;
- `catalogo.png` — catálogo, busca e categorias;
- `impressora.png` — descoberta e conexão com a NIIMBOT B1;
- `etiqueta.jpg` — etiqueta física impressa;
- `bula-qr.png` — leitura do QR Code e abertura da bula.

Antes de publicar, recorte a barra de notificações quando ela exibir informações pessoais e confira se nenhum endereço do projeto Supabase ou e-mail de teste precisa ser ocultado.
