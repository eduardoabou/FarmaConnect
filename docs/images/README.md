# Materiais visuais do portfólio

Arquivos utilizados pelo README principal:

- `catalogo.jpg` — catálogo, busca, categorias e impressão individual;
- `catalogo-qr.jpg` — indicador de bula por QR Code e última sincronização;
- `fluxo-farmaconnect.png` — fluxograma do acesso até a impressão da etiqueta;
- `preview-video.jpg` — capa clicável do vídeo demonstrativo;
- `../videos/demonstracao-farmaconnect.mp4` — demonstração do aplicativo com a NIIMBOT B1.

Os materiais foram revisados em 15 de novembro de 2026. Eles exibem somente catálogo e contas demonstrativas, senha mascarada e informações operacionais da impressora. Não contêm chaves, tokens, URLs privadas, credenciais administrativas ou dados de clientes.

Antes de substituir qualquer arquivo, revise novamente a barra de notificações, os campos de autenticação, nomes Bluetooth, QR Codes e etiquetas impressas. Nunca publique uma senha visível, chave do Supabase, endereço administrativo ou informação real de cliente.
